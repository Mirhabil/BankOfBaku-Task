# ✖️ Multiplication Table Generator in Dart (Console)

A simple and interactive Dart console application that generates a multiplication table for any number up to a limit you specify. Great for beginners learning Dart or practicing console input/output! 🚀

---

## 🧰 Features

- 🔢 Generate multiplication tables for any number
- 📈 Custom limit for the table (e.g. up to 10, 20, etc.)
- 🛡️ Validates user input to prevent crashes
- 🎓 Beginner-friendly and easy to understand

---

## 📦 Requirements

- Dart SDK (>=2.12.0)

> You can install it from [https://dart.dev/get-dart](https://dart.dev/get-dart)

---

## 🚀 How to Run

1. Download or clone the repository.
2. Open your terminal and navigate to the project folder.
3. Run the file using:

```bash
dart run multiplication_table.dart
